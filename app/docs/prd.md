# Product Requirements Document (PRD)

## Vision
Build a premium recurring bill and subscription tracker that helps users never miss payments while remaining privacy-first, offline-capable, and secure.

## Goals
- Track recurring bills
- Intelligent reminders
- Offline-first experience
- Multi-device sync
- Strong security with Row Level Security
- Future-ready household support

## MVP
- Authentication
- Bill CRUD
- Categories
- Dashboard
- Reminder engine
- Push notifications
- Configurable email notifications
- Timeline
- Payment history
- Receipt uploads
- Offline sync

## Success Metrics
- Bill reminders delivered reliably
- Zero cross-user data leaks
- Offline edits sync correctly
- Low reminder failure rate
